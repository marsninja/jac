- **Fix: a dev hot reload no longer fails with "Cannot release compiler state during compilation" or leaves the compiler stuck**: The hot reloader re-prepared the app on the watcher thread while the first request after the change reloaded the entry module on its own thread, which ran a second preparation. When they overlapped, the reload failed with that error, and the compiler's nesting counter could be left above zero, so every later reload failed the same way until a restart. Compiles, preparations and the post-prepare release now hold one process-wide re-entrant lock, so a second thread waits instead of interleaving.
