- **Fix: Native ternaries whose branches lower differently**: `a if cond else b` now unifies its two branch representations through one shared rule (branches sharing a lowering keep it, an all-pointer pair keeps the first member's layout, a genuinely mixed pair boxes to a tagged `jacval`), instead of building a phi whose incoming values had different LLVM types and failing the whole module. Branches that already shared a lowering are unchanged and never box, and the closure-typed case still wraps a bare function into the closure layout rather than reinterpreting it. Nested ternaries and ternaries in call-argument position are covered.
- **Change: Declared multi-member unions lower by representation, not by first member**: `_lower_type` previously gave a declared union whatever its FIRST member lowered to, so `int | str`, `int | float` or `bool | str` silently reinterpreted the other members through that layout. It now lowers every member and applies the same unification rule, so a mixed union becomes a tagged `jacval` in every position `_lower_type` feeds: parameters, returns, and module globals. This is representation-visible and is recorded in the sealed `NativeFuncLayout`, but it needs no `NATIVE_ABI_VERSION` bump: that constant versions the schema of the layout descriptor, which is unchanged, and stale artifacts are already invalidated per release by the `jaclang` version mixed into the module cache key. All-pointer and single-representation unions lower exactly as before.
- **Fix: Boxed operands in native arithmetic diagnose instead of crashing**: arithmetic on a tagged `any` value (`v + 1` where `v: any`) raised an internal `AttributeError` out of the codegen pass. It now reports E5092, so the module demotes to the server backend the way every other unlowerable shape does. Dynamic arithmetic on boxed values remains unimplemented.
- **Fix: Scalar constant initializers are no longer emitted into non-scalar global slots**: a `glob` whose declared type lowers to an aggregate (a union boxed to `jacval`) now initializes through the runtime glob-init path instead of trying to build a scalar LLVM constant of a struct type.
