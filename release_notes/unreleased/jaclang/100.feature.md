- **Feature: opt-in `native-clean` lint rule (W3057)**: `select = ["native-clean"]` in `[check.lint]` reports code that needs Python semantics the native backend cannot compile: `any`, `Any` or `object` as a type (nested annotations included), `getattr`/`setattr`/`hasattr`/`delattr`, `eval`/`exec`/`compile`/`__import__` and `importlib` imports, `*args`/`**kwargs` parameters, and Python standard-library imports that the bundled native standard library does not provide. It is on only when named: `"default"` and `"all"` leave it off. It reports only and never rewrites code.
