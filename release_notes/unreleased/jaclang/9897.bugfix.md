- **Fix: a `className` passed to a jac-shadcn component no longer strips its own classes**: `Empty`, `Kbd`, `Item`, `ButtonGroup`, `NativeSelect`, `SelectValue` and the `Sidebar` family spread the caller's props after their own `className`, so the caller's bare value replaced the merged one and the component lost its base classes (`Empty` with a `className` rendered left-aligned instead of centered). The merged `className` now comes after the spread, as does the wrapped `onClick` of `SidebarTrigger`. Components already added to a project keep the old order until they are removed and installed again (`jac remove --shadcn <name>`, then `jac install --shadcn <name>`); installing over an existing component changes nothing.
