- **Fix: jac native now narrows optionals and boxed unions flow-sensitively**: a use of a function-local that a test proves non-None (or proves to be a given union member) reads the payload directly, with no runtime tag check, exactly as the sv/bytecode backend already did. Previously `ids[0]` on a guarded `list[int] | None` did not lower at all (`Type of #1 arg mismatch: %"List.i64"* != %"JacOpt.1"`) and `x + 1` inside `if isinstance(x, int)` on a boxed value crashed the emitter; `len(ids)` did lower but paid a checked unwrap the guard had already made unreachable. `is None` / `is not None` / `!= None` guards, truthiness, if/else, early `return` / `continue` / `raise` guards, and `isinstance` are all covered, for pointer-payload and scalar-payload optionals alike. The narrowing fact is read off `Expr.type`, where the type checker already stamps it, rather than re-derived by a second analysis in the backend, so native and sv agree by construction. Narrowing declines wherever the proof does not reach: attributes, globals and closure cells (a callee can rebind them behind the checker's intra-procedural walk), a value whose enclosing loop rebinds it after the use (the checker skips back edges at loop headers), and the operand of a `None` test, which must stay a tag read. In every declining case the checked unwrap the code had before is preserved, so a use that was raising still raises. Separately, a `case None` arm over a subject whose lowered type cannot represent None now folds to false instead of emitting an invalid null compare against a scalar.
